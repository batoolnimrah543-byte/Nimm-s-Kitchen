# Nimm's Kitchen Website

A website for **Nimm's Kitchen**, a restaurant in Karachi, Pakistan.

## Tech Stack

- HTML
- CSS
- JavaScript

## Purpose

To give Nimm's Kitchen an online presence where customers can see the menu, browse food photos, and place orders.

## What It Does

- Shows the restaurant's homepage and menu
- Lets customers add dishes to a cart
- Displays a photo gallery of the food
- Lets customers fill in an order form, which opens their email app with the order ready to send
